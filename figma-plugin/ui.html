📋 Quick Setup Steps

  1. 1. Run npm run build:figma in your project
  2. 2. Upload figma-demo.html and dist/ folder to a web host
  3. 3. Update the URLs above with your hosted URL
  4. 4. Click "Create Frame" to add to your design
  5. 5. Replace the frame with an Embed component using your URL
